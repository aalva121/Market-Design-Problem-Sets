# Market-Design-Problem-Sets
Contains all problems set files for ECN 591 Seminar - Market Design
ECN 591 Seminar - Market Desgin is a graduate level course for students at Arizona State University. The course covers the theories surrounding Market Design and how we can fix real-world market failures through well-designed rules and algorithms. Students will be able to understand strategic behavior in market design and learn how to make strategic choices themselves in market design programs like VS Code and other applications.
